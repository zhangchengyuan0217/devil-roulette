# 用户体验优化 · 素材需求清单（按优先级）

基于当前仓库盘点（2026-07-24）：角色 / 道具立绘、道具 SFX、弹药立绘、`your_turn` 音画已较齐；**核心开枪结算几乎无声**，状态角标与牌背/数量牌等仍偏「程序 UI」。

原则：先补「玩家每局必经历、且当前反馈最弱」的环节；道具立绘与 14 条道具音效暂可不扩量。

### P0 弹药音效 · AI 生成描述文案

规格建议：单声道或立体声均可；时长约 **0.6–1.2s**；无 BGM、无人声、无旁白；结尾自然衰减；响度与现有道具 SFX（约 -6～-3 dB peak）接近，**实弹可略响一档**。

#### 1. 实弹 · `shoot_live.mp3`

> 近距离单发霰弹/左轮实弹击发音效。短促有力的枪口爆破，带一层低沉胸腔共鸣与金属枪机回弹，短暂回响后快速衰减。压迫感强、杀伤感明确，适合赌命桌游「揭开红壳实弹」瞬间。不要连发、不要空膛咔嗒、不要人声、不要音乐。时长约 0.8–1.1 秒。

#### 2. 空弹 · `shoot_blank.mp3`

> 近距离空包弹 / 空膛击发音效。清脆的撞针咔嗒与短促气爆，几乎没有沉重的杀伤冲击，带一点干涩的金属空响与极短余音。听感应明显轻于实弹，传达「虚惊一场」的松口气，适合揭开蓝壳空弹。不要沉重低音轰鸣、不要连发、不要人声、不要音乐。时长约 0.5–0.8 秒。

#### 3. 特殊弹 · `shoot_special.mp3`

> 近距离特殊弹药击发音效。在短促枪响基础上叠一层不寻常的金属嗡鸣或高频闪烁感，音色介于实弹与空弹之间，带一点「异质、银光、命运偏移」的质感，呼应紫壳特殊弹与银刺互动。辨识度要高，但不要做成法术或科幻激光。无人声、无音乐。时长约 0.7–1.0 秒。

## 建议制作批次

1. **第一批（约 8 个音效）**：live / blank / special / flip / damage / heal / vest_block / win  
   → 立刻拉齐「开枪戏」体感。
2. **第二批（约 5 个 SVG + 4 个 UI 音）**：chain / shotgun / sniper / reverse + draw / discard / ammo_load / round_start  
   → 桌面信息密度与回合节奏。
3. **第三批**：角色技能音（先响尾蛇、双管、夜枭、追香）+ 修正 sniper/vest 的 sm。
4. **第四批**：牌背、数量牌 1–6、骰子、BGM、favicon。

## 非素材但同级的体验债（供排期参考）

下列不依赖新美术，却同样影响 UX；可与 P0–P1 并行用代码推进：

- 开枪揭示已有完整动画，但无配套音效时间轴（揭幕 / 落地 / 翻面应对齐）
- 效果条「反转/霰弹/狙击挂起」可改为图标 pills，减少读字
- 首次进入房间的静音提示（浏览器需手势解锁音频，现有 unlock 逻辑可配一句文案）
- 局内规则入口是否够显眼（文案已在 `assets/rule/`）
